# ছবি ফোল্ডার (Images)

এই ফোল্ডারের ছবিগুলো মূল অ্যাপের Supabase Storage-এ রাখা ছবির জায়গায় বসানো
**প্লেসহোল্ডার** (নমুনা ডিজাইন)। আসল লোগো/ব্যানার থাকলে নিচের নামে সেভ করে
এখানে replace করে দিন — `index.html` বা কোনো JS ফাইল বদলানোর দরকার নেই।

| ফাইলের নাম            | ব্যবহৃত হয় কোথায়                      | প্রস্তাবিত সাইজ    |
| --------------------- | --------------------------------------- | ------------------ |
| `logo.png`            | লগইন স্ক্রিন + অ্যাপ হেডারের ছোট লোগো   | ৩০০×৩০০ (বর্গাকার) |
| `banner-loading.webp` | লোডিং স্ক্রিনের ব্যানার                 | ৬০০×৩০০            |
| `banner-auth.webp`    | লগইন স্ক্রিনের ওপরের ব্যানার            | ৮০০×৩০০            |
| `ad-banner.webp`      | ড্যাশবোর্ডের বিজ্ঞাপন/প্রমোশনাল ব্যানার | ৮০০×২০০            |

## নতুন ছবি যোগ করতে চাইলে

পণ্যের ছবি, স্টাফের প্রোফাইল ছবি ইত্যাদি নতুন ফিচার হিসেবে যোগ করতে চাইলে:

1. এই ফোল্ডারে (অথবা এর ভেতরে সাবফোল্ডার বানিয়ে, যেমন `assets/images/products/`) ছবি রাখুন
2. HTML/JS-এ পাথ দিন যেমন: `assets/images/products/rice.jpg`

localStorage-এ বড় ছবি (base64) জমা রাখা এড়িয়ে চলাই ভালো, কারণ ব্রাউজার স্টোরেজ
সীমিত (সাধারণত ৫-১০ MB)। এই ফোল্ডারে সরাসরি ফাইল রাখাই সবচেয়ে সহজ ও নিরাপদ উপায়।
